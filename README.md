# DevelopersHub Data Science Internship

This repository contains all assigned tasks completed during the Data Science Internship at DevelopersHub Corporation.

## 📌 Task 01 – Iris Dataset Visualization
Performed exploratory data analysis and data visualization using Python libraries such as Pandas, Matplotlib, and Seaborn.

## 📌 Task 02 – Credit Risk Prediction
Built a Logistic Regression model to predict loan approval using financial data.

## 📌 Task 03 – Customer Churn Prediction
Developed a classification model to predict customer churn based on demographic and financial features.

## 📌 Task 04 – Insurance Claim Prediction
Implemented a Linear Regression model to predict medical insurance charges based on BMI, age, and smoking status.

- Python

- Matplotlib / Seaborn
- Scikit-learn
